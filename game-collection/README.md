# 🎮 게임 9000

30가지 오리지널 미니게임 장르를 각각 300가지로 변형해 **총 9,000개의 게임**을 한곳에 모은 웹 게임 모음집입니다.

```bash
cd game-collection
npm install
npm run dev   # http://localhost:5175
```

## 구성

| 분류 | 장르 |
| --- | --- |
| 액션 | 뱀 키우기, 낙하물 피하기, 점프 러너, 동굴 비행, 은하 방어전 |
| 아케이드 | 벽돌 부수기, 패들 결투, 과일 받기, 두더지 잡기, 과녁 사격, 블록 쌓기 |
| 퍼즐 | 카드 짝맞추기, 숫자 슬라이드, 지뢰 탐색, 불 끄기 퍼즐, 미로 탈출, 숫자 순서 터치 |
| 두뇌 | 반응 속도, 색 순서 기억, 암산 챌린지, 색깔 함정, 타자 방어 |
| 보드 | 삼목 대결, 오목 |
| 스포츠 | 골키퍼 선방, 볼 리프팅, 승부차기, 자유투 타이밍 |
| 리듬 | 리듬 레인, 타이밍 스톱 |

각 장르마다 다음 조합으로 300개의 변형이 만들어집니다 (5 × 5 × 3 × 4 = 300):

- **테마 5종** — 미드나잇, 네온, 정글, 심해, 노을
- **속도 5단계** — 느긋한(0.7×), 보통, 빠른, 광속, 지옥의(1.8×)
- **크기 3단계** — 미니, 표준, 메가 (판 크기·오브젝트 크기·문제 난이도가 달라짐)
- **모드 4종** — 클래식(목숨 3), 타임어택(60초), 하드코어(목숨 1·점수 2배), 젠(120초·실패 없음)

게임마다 고유 번호(#1~#9000)와 고정 시드가 있어서 같은 번호는 항상 같은 배치로 시작합니다.
`index.html#1234` 처럼 주소로 특정 게임에 바로 들어갈 수 있습니다.

## 기능

- 검색(이름·번호), 분류/장르/모드/속도 필터, 페이지 이동
- 🎲 랜덤 게임, ★ 즐겨찾기, 🕘 최근 플레이, 🏆 게임별 최고 기록 (브라우저 localStorage에 저장)
- 키보드·마우스·터치 지원, P 일시정지, R 재시작, Esc 목록으로

## 코드 구조

- `src/core/catalog.ts` — 번호 → (장르, 테마, 모드, 속도, 크기) 변환
- `src/core/runner.ts` — 게임 루프, 목숨·시간·점수 규칙, HUD
- `src/engines/*.ts` — 장르별 게임 구현 (`Engine` 인터페이스)

새 장르를 추가하려면 `Engine`을 하나 만들어 `catalog.ts`의 `ENGINES`에 넣으면 300개 변형이 자동으로 생깁니다.
