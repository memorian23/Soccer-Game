# ⌨️ 키보드 월드 (3D)

거대한 키보드 위를 달려 **Enter** 키에 도착하면 성공! 성공할 때마다 **100,000,000,000,000 🏆**.

```bash
cd keyboard-world
npm install
npm run dev   # http://localhost:5175
```

- 조작: WASD/방향키 이동 · Space 점프 · 마우스 드래그 시점 · 휠 줌 · R 처음부터
- 레벨 6개 (앞 레벨을 성공하면 다음 레벨이 열림)
- 상점: 발자국 / 무지개·불꽃·별가루 꼬리 — 모두 1 🏆
- 속도 (화면 아래): 숫자를 적고 k / m / b / t 를 누르거나 `5m`처럼 입력 후 Enter.
  k < m < b < t 순서로 빨라지고, 숫자가 클수록 빨라진다.
