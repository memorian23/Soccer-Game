# ⌨️ 키보드 월드 (3D)

거대한 키보드 위를 달려 **Enter** 키에 도착하면 성공! 성공할 때마다 **100,000,000,000,000 🏆**.

```bash
cd keyboard-world
npm install
npm run dev   # http://localhost:5175
```

- 조작: WASD/방향키 이동 · Space 점프(장애물 넘을 때) · 마우스 드래그 시점 · R 처음부터
- 키보드를 누를수록 속도가 올라간다 (키 한 번에 +1). 출발 광장의 **100× 런닝기구** 위에서 누르면 한 번에 +100.
- 속도 표시는 k < m < b < t 단위.
- 코스 5개: 틈 없는 달리기 길 + 장애물(고정/좌우/위아래). 앞 코스를 성공하면 다음 코스가 열림.
- 상점: 발자국 / 무지개·불꽃·별가루 꼬리 — 모두 1 🏆
